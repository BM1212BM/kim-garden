Kim · นโยบายความเป็นส่วนตัว

ปรับปรุงล่าสุด 29 ตุลาคม 2569 (เพิ่มการอ่านนัดหมายแบบอ่านอย่างเดียว)

Kim เป็นผู้ช่วยฝึกวินัยบน LINE ที่ช่วยวางแผนและติดตามเป้าหมายของผู้ใช้ หน้านี้อธิบายว่า Kim เก็บข้อมูลอะไร และใช้ทำอะไร

ข้อมูลที่ Kim เก็บ

  • LINE user ID และชื่อที่แสดงใน LINE
  • เป้าหมาย งาน แผนรายวัน ผลการทำ และข้อความที่ผู้ใช้คุยกับ Kim ในแชทส่วนตัว
  • ในแชทกลุ่ม: เฉพาะแผนและรายการงานของกลุ่ม ไม่เก็บข้อความแชทอื่น
  • ถ้าผู้ใช้เลือกเชื่อม Google Calendar: รหัสสำหรับเข้าถึง (refresh token) และรหัสปฏิทิน "Kim 🌱"

Google Calendar

  • Kim ขอสิทธิ์ 4 อย่าง: ดูช่วงเวลาที่ไม่ว่าง (free/busy), ดูรายชื่อปฏิทิน, อ่านชื่อและเวลาของนัดหมาย (อ่านอย่างเดียว) และจัดการเฉพาะปฏิทิน "Kim 🌱" ที่ Kim สร้างเอง
  • Kim แก้ไข ลบ หรือสร้างนัดในปฏิทินอื่นของผู้ใช้ไม่ได้
  • ชื่อและเวลานัดใช้เพื่อจัดเวลางานให้หลบนัด และแสดงให้ผู้ใช้เห็นในแชท LINE ว่าวันนั้นมีนัดอะไร ไม่ถูกเก็บลงฐานข้อมูล
  • เมื่อผู้ใช้คุยกับ Kim ชื่อนัดของวันนี้และพรุ่งนี้อาจถูกส่งไปพร้อมข้อความให้ผู้ให้บริการ AI เพื่อให้คำตอบเข้ากับตารางของผู้ใช้ และไม่ถูกใช้ฝึกโมเดล
  • การใช้ข้อมูลที่ได้จาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

การใช้และการแบ่งปันข้อมูล

  • ใช้เพื่อวางแผน เตือน และสรุปความคืบหน้าให้ผู้ใช้เท่านั้น
  • ข้อความบางส่วนถูกส่งไปประมวลผลกับผู้ให้บริการ AI เพื่อสร้างคำตอบ (รวมชื่อนัดของวันนี้และพรุ่งนี้ ตามที่ระบุด้านบน)
  • ไม่ขาย ไม่ใช้ทำโฆษณา และไม่แบ่งปันข้อมูลให้บุคคลอื่น
  • ข้อมูลเก็บในฐานข้อมูล Supabase ที่จำกัดการเข้าถึง

สิทธิ์ของผู้ใช้

  • ดูสิ่งที่ Kim จำไว้: เมนู → ตั้งค่า → คิมจำอะไรไว้
  • ยกเลิกการเชื่อม Google: เมนู → ตั้งค่า → Google Calendar → ยกเลิกการเชื่อม หรือถอนสิทธิ์ที่ myaccount.google.com/permissions
  • ลบข้อมูลทั้งหมด: เมนู → ตั้งค่า → ลบข้อมูลทั้งหมด (ลบถาวรทันที)

Kim · Privacy Policy

Kim is a LINE assistant that helps users plan and keep track of their own goals.

  • Data stored: LINE user ID and display name; goals, tasks, daily plans, results and 1:1 chat messages; for group chats only the group's plan and task list; if Google Calendar is connected, a refresh token and the ID of the "Kim 🌱" calendar.
  • Google Calendar: Kim requests free/busy access, read-only access to the calendar list and to event titles and times, and access to the "Kim 🌱" calendar it creates. It cannot create, change or delete events in the user's other calendars. Event titles and times are used only to schedule tasks around them and to show the user, in LINE, what is on their calendar that day; they are not stored. When the user chats with Kim, today's and tomorrow's event titles may be sent with the message to an AI provider to tailor the reply. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Use and sharing: data is used only to plan, remind and summarise progress for the user. Some chat text is processed by an AI provider to generate replies (including today's and tomorrow's event titles, as described above). Data is not sold, used for advertising, or shared with third parties.
  • Your controls: disconnect Google in Kim's settings or at myaccount.google.com/permissions; delete all data from Kim's settings at any time.
